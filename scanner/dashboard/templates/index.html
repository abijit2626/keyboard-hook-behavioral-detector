How Risk Is Calculated

No single signal can escalate a process on its own — every path to HIGH or MEDIUM starts with a rule-based trigger.

01

Rule Engine

Capability detection (hook DLLs, signatures, execution context) plus temporal persistence — gated event weights that decay over time.

02

Malware ML

A RandomForest classifier trained on 5,210 real labeled executables (the ClaMP dataset) scores whether a binary's PE structure looks like malware in general.

03

Keylogger ATT&CK Fingerprint

A deterministic import-table scan weighted against MITRE ATT&CK techniques (T1056.001 and related) for input-capture-specific capability.

This page polls /api/state every 3s and only ever displays what temporal_risk_engine.py already decided — nothing is re-scored client-side.
